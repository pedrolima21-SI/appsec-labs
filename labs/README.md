# Laboratórios

Índice de exercícios educacionais e defensivos. Use código próprio, exemplos didáticos ou ambientes explicitamente autorizados.

## Exercícios

- [`01 — Revisão de controle de acesso`](01-access-control-review/): exercício documental sobre papéis, permissões, menor privilégio e decisões pendentes em cenário fictício. Não é um teste de sistema real.

## Como registrar o trabalho

Para cada exercício, descreva o objetivo, o escopo, o que foi revisado, observações verificadas, melhorias propostas e limitações. Marque claramente resultados esperados que ainda não foram testados. Use dados fictícios e sanitizados.

## Regras

- Leia o escopo e os pré-requisitos antes de começar.
- Não teste sistemas sem autorização explícita.
- Não inclua credenciais, tokens ou dados pessoais.
- Prefira revisão preventiva de código e configurações locais.
