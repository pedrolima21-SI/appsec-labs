# Laboratórios

Índice de exercícios educacionais e defensivos. Use código próprio, exemplos didáticos ou ambientes explicitamente autorizados.

## Exercícios

- [`01-access-control-review/`](01-access-control-review/): revisão documental de uma matriz de acesso e das regras de autorização.

## Como registrar o trabalho

Para cada exercício, descreva o objetivo, o escopo, o que foi revisado, as observações verificadas, as melhorias propostas e as limitações. Use dados fictícios e sanitizados.

## Regras

- Leia o escopo e os pré-requisitos antes de começar.
- Não teste sistemas sem autorização explícita.
- Não inclua credenciais, tokens ou dados pessoais.
- Prefira revisão preventiva de código e configurações locais.
